# F1-F12 功能键实现计划

## 目标

为虚拟键盘中的 `F1-F12` 提供尽可能接近浏览器环境的默认行为，并允许业务侧按键级别或统一入口覆写。

## 设计原则

1. 优先提供“网页可控”的默认行为，不承诺浏览器 chrome / 操作系统级能力。
2. 对于浏览器安全限制无法真正完成的行为，提供可监听、可覆写、可降级的统一事件出口。
3. 默认行为执行前，优先让业务侧决定是否接管；业务侧返回“已处理”后，不再执行内置逻辑。
4. 保留现有 `FunctionKeyboard -> useInput -> onFunction` 事件链路，不破坏已有 `onClick / onKeyDown / onKeyUp` 用法。

## F1-F12 默认行为规划

### F1

- 默认行为：派发帮助事件并尝试打开可配置帮助链接
- 默认降级：未配置帮助链接时，仅派发事件，不强行跳转
- 覆写建议：业务可接管为“打开帮助弹窗 / 使用说明 / 快捷键面板”

### F2

- 默认行为：派发功能键事件，不内置副作用
- 默认降级：仅事件通知
- 覆写建议：业务可接管为“重命名 / 编辑当前项 / 切换编辑态”

### F3

- 默认行为：优先用当前选中文本、输入框选区文本或候选输入文本调用页内查找
- 默认降级：无可查找文本时，仅派发事件
- 覆写建议：业务可接管为“打开站内搜索面板 / 聚焦搜索框”

### F4

- 默认行为：派发功能键事件，不模拟地址栏/关闭窗口
- 默认降级：仅事件通知
- 覆写建议：业务可接管为“打开命令面板 / 最近记录 / 下拉面板”

### F5

- 默认行为：刷新当前页面
- 默认降级：优先 `location.reload()`，异常时退化为事件通知
- 覆写建议：业务可接管为“局部刷新 / 数据重载 / 重新请求”

### F6

- 默认行为：优先聚焦页面内可用搜索框或首个可交互输入框
- 默认降级：找不到目标时，仅派发事件
- 覆写建议：业务可接管为“聚焦主搜索框 / 地址输入框 / 扫码输入框”

### F7

- 默认行为：切换组件内“光标浏览模式”状态并派发事件
- 默认降级：仅维护内部状态与事件通知，不控制浏览器级 caret browsing
- 覆写建议：业务可接管为“切换辅助操作模式 / 键盘导航模式”

### F8

- 默认行为：派发功能键事件，不内置副作用
- 默认降级：仅事件通知
- 覆写建议：业务可接管为“播放/暂停 / 展开侧栏 / 快速录入”

### F9

- 默认行为：派发功能键事件，不内置副作用
- 默认降级：仅事件通知
- 覆写建议：业务可接管为“提交校验 / 打开统计 / 刷新局部面板”

### F10

- 默认行为：派发功能键事件，不模拟浏览器菜单栏
- 默认降级：仅事件通知
- 覆写建议：业务可接管为“打开顶部菜单 / 操作菜单 / 工具菜单”

### F11

- 默认行为：切换浏览器全屏
- 默认降级：基于 Fullscreen API，失败时仅派发事件
- 覆写建议：业务可接管为“容器全屏 / 大屏模式 / 沉浸模式”

### F12

- 默认行为：派发功能键事件，不尝试打开开发者工具
- 默认降级：仅事件通知
- 覆写建议：业务可接管为“打开调试面板 / 日志抽屉 / 诊断信息”

## 实现步骤

1. 扩展类型定义，为 `VirtualKeyboard`、`CompositionKeyboard`、`useInput` 增加功能键默认行为配置与覆写回调。
2. 在 `useInput` 中实现统一的功能键分发器，支持“先覆写，后默认”的执行顺序。
3. 实现 F1-F12 默认行为，并为受浏览器限制的键位补充清晰降级逻辑。
4. 将功能键上下文通过自定义事件暴露给外部，方便非 React 监听场景接入。
5. 更新 README 与 `FunctionKeyboard` / `useInput` 文档，标注各键默认行为和限制。
6. 运行 `lint`、`build` 验证实现结果，修复顺路暴露的类型问题。

## 风险与限制

- `F6`、`F10`、`F12` 等浏览器 chrome 级行为无法被网页 JavaScript 真正接管。
- `F3` 的“页内查找”依赖 `window.find`，兼容性有限，需要提供事件和覆写兜底。
- `F11` 全屏依赖用户手势与 Fullscreen API，可被浏览器策略拦截。
- `F5` 刷新会导致页面重载，业务若有未保存数据，应优先覆写。

## 验收标准

- 点击虚拟 `F1-F12` 时，全部键位都有明确、可预测的执行结果。
- 业务侧可以统一覆写，也可以按单个 `Fn` 键覆写。
- 默认行为失败时不会抛出未捕获异常。
- 文档中明确说明默认行为、浏览器限制和覆写方式。
